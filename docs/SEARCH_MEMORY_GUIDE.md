# Search Memory - User Guide

## 🔍 Quick Start

Новый **Search Memory** работает как Command Palette - быстрый и удобный поиск по всей памяти проекта.

---

## 🚀 Как открыть поиск

### **Способ 1: Keyboard Shortcut (рекомендуется)**
```
Ctrl + K  (Windows/Linux)
⌘ + K     (Mac)
```

### **Способ 2: Кнопка в Header**
Нажмите кнопку **"🔍 Search ⌘K"** в верхней панели

---

## 💡 Как использовать

### **1. Базовый поиск**
1. Откройте палитру (Ctrl/⌘ + K)
2. Начните вводить текст
3. Результаты появятся автоматически

### **2. Фильтры**
Используйте быстрые фильтры для уточнения:
- **⭐ Favorites** - только избранное
- **🎯 Decisions** - архитектурные решения
- **💡 Lessons** - уроки и знания
- **📚 Docs** - документация
- **⚠️ Constraints** - ограничения

**Как работает:** Кликните на фильтр, чтобы включить/выключить

### **3. Recent Searches**
Когда поле поиска пустое, видны последние 5 запросов:
- Клик по запросу → повторить поиск
- История сохраняется локально

---

## ⌨️ Keyboard Navigation

### **В режиме поиска:**
| Клавиша | Действие |
|---------|----------|
| `Ctrl/⌘ + K` | Открыть/закрыть палитру |
| `Esc` | Закрыть палитру |
| `↑` `↓` | Перемещение по результатам |
| `Enter` | Выбрать результат |
| `Type...` | Автоматический поиск |

## 🎯 Результаты поиска

### **Карточка результата показывает:**
- 🎯 **Иконка типа** - визуальное распознавание
- **Название** - label памяти
- **Badges** - тип, scope, score
- **Snippet** - первые 140 символов текста

### **Действия:**
- **Клик** - перейти к Memory view и показать в графе
- **Hover** - подсветка
- **Arrow keys** - навигация

---

## 🔗 Интеграция с Memory View

После выбора результата:
1. ✅ Автоматически переключается на Memory view
2. ✅ Находит узел в графе (если есть)
3. ✅ Показывает детали в боковой панели
4. ✅ Центрирует граф на выбранном узле

---

## 💾 Recent Searches

### **Что сохраняется:**
- Последние 5 поисковых запросов
- Хранится локально (localStorage)
- Не синхронизируется между устройствами

### **Управление:**
- Автоматическое сохранение при каждом поиске
- Дубликаты не создаются
- FIFO (First In, First Out) - старые удаляются

## 🎨 UI/UX Features

### **Live Search**
- Результаты появляются по мере ввода
- Debounce 300ms - не перегружает сервер
- Loading state не показывается (быстро)

### **Visual Feedback**
- Hover effects на результатах
- Active state на фильтрах
- Highlighted selection для keyboard nav
- Smooth animations (fade, slide)

### **Responsive Design**
- Desktop: 680px max-width
- Mobile: 95% width
- Touch-friendly на всех устройствах

## 🐛 Troubleshooting

### **Поиск не работает?**
1. Проверьте, что проект выбран
2. Убедитесь, что в памяти есть данные
3. Попробуйте обновить страницу

### **Keyboard shortcuts не работают?**
1. Убедитесь, что фокус не в input поле
2. На Mac используйте ⌘K, не Ctrl+K
3. Проверьте, не перехватывает ли браузер шорткат

### **Recent searches не сохраняются?**
1. Проверьте localStorage в браузере
2. Очистите кеш и попробуйте снова
3. Проверьте права доступа к localStorage

## 💡 Pro Tips

### **1. Используйте фильтры**
Комбинируйте фильтры для точного поиска:
- "architecture" + 🎯 Decisions
- "bug" + 💡 Lessons

### **2. Keyboard-first workflow**
```
⌘K → Type → ↓↓ → Enter
```
Полностью без мыши!

### **3. Recent searches как bookmarks**
Часто используемые запросы будут в истории - быстрый доступ
