Memory Embeddings

            

            
How Ask and Search pick similar
              memories by meaning. Connect the embedding model under AI → Providers → Embeddings; here you only tune
              retrieval and the vector engine.

            

              

                Retrieval tuning
                
Trade-offs between recall,
                  precision, and latency when ranking memories for a query.

                

                  
                  
                  
                  
                

                

                  
                

              

              

                SQLite
                  vector search
                
Ask and
                  Search rank memories by meaning. sqlite-vec does that ranking inside SQLite, so results stay fast as
                  the graph grows. Without it ArchitectOS still works — it uses an in-memory Python index, which gets
                  slower with more memories.

                
Turn this on when
                  memory is large. Needs a Python that can load SQLite extensions (Homebrew or conda). The python.org
                  macOS installer cannot.

                
This
                  packaged app was checked at install. sqlite-vec is baked in at build time and cannot be pip-installed
                  into the bundle. If it is off, rebuild with Homebrew or conda Python, then reinstall.

Rebuild Index
                recomputes vectors for existing memories with the current embedding model. Use after changing
                provider/model; can take a while on large graphs.
